# Sales Data Analysis & Prediction using Python

## Project Overview
This project analyzes sales data using Python and predicts next month's sales using Machine Learning.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Key Features
- Sales data cleaning and analysis
- Total sales calculation
- Product-wise sales analysis
- Category-wise sales analysis
- Monthly sales trend analysis
- Top-selling product identification
- Missing value checking
- Next-month sales prediction using Linear Regression

## Results
- Total Sales: ₹693,000
- Highest Revenue Product: Laptop
- Highest Revenue: ₹4,40,000
- Best-selling product by quantity: Mouse
- Predicted Next Month Sales: ₹84,000

## Conclusion
The project helps understand sales performance and demonstrates how Python and Machine Learning can be used for business data analysis and sales prediction.
